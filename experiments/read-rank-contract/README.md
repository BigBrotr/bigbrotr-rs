# Read and rank contract oracles

Run `python3 experiments/read-rank-contract/probe.py`. The standard-library
program solves three tiny stationary systems by exact rational Gaussian
elimination and bounds the error of floating candidates using an exact rational
residual. This validates the contraction argument and reference examples, not a
future production floating-point error estimator or large-graph performance.

The traversal fixture distinguishes fixed candidate admission from current public
eligibility, including expiry, replacement, private input and backdated arrival.
It is a semantic example, not a database, encrypted cursor or socket test.
